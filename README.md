# 오늘도, 한 끼

쿠지 생존 게임 기획서에 기반한 HTML 프로토타입입니다. `index.html`을 브라우저에서 열면 실행됩니다. `assets` 폴더를 같은 위치에 유지해 주세요. 설치나 빌드가 필요 없습니다. 외부 글꼴 연결이 없어도 기본 글꼴로 플레이할 수 있습니다.

## 구현 범위

- 하루 30장 공유 덱: A 1 / B 3 / C 4 / D 5 / E 2 / F 15, 장당 $5
- 쿠지 선택 → 개봉 연출 → 식사 → 판매를 하루 3회 진행
- 4인 가족의 개별 포만도: 나 30 / 배우자 25 / 아이 15 / 어르신 20, 고정 판매가, 잔여 등급 및 확률 표시
- 아침식사 / BBQ / 디저트 테마 순환
- 지속 효과가 있는 유물 5종 및 소모품 3종
- 희귀 보상 종이 파편 연출, 선택형 효과음, 1920×1080 고정 화면 및 비율 유지 축소, 키보드 조작
- 브라우저 자동 저장, 새 게임, 승리 / 실패 화면

## 프로토타입에서 정한 규칙

기획서에서 미정인 시작 자금은 $75, 목표는 7일 생존으로 정했습니다. 하루 종료 시 한 사람이라도 개별 필요량을 채우지 못하면 실패합니다. 남은 음식은 기본 2개를 포만도 순으로 보관하고 보관 상자로 제한을 해제합니다. 음식 수치와 암시장 가격은 프로토타입용이며 추가 플레이테스트로 조정할 수 있습니다. 쿠지 결과는 구매 시 확정 및 자동 저장되어 개봉 중 새로고침해도 보상이 사라지지 않습니다.

기획서의 음식 5~10종 권장은 테마별 6종, 총 18종으로 확장했습니다. 유물 중 행운의 동전, 촛대, 식칼과 소모품 카드 교환권, 흥정 쪽지는 이번 버전에 포함하지 않았습니다.

자동 저장은 실행한 브라우저와 주소에 종속됩니다. 저장이 차단된 환경에서도 현재 세션의 게임은 동작합니다.

## 디스토피아 아트 업데이트

숯빛 배경, 거친 해칭 질감, 찢어진 배급권과 녹슨 도장, 피난처 가족 삽화를 적용했습니다. 세 테마는 제분소 배급 / 도축장 회수 식량 / 폐쇄 상가 비축품으로 재해석했습니다. 규칙 및 저장 형식은 동일합니다.

가족 이미지는 내장 image_gen 도구로 새로 생성했습니다. 이미지: `assets/family-shelter.png`, 스타일: `assets/dystopia.css`, 생성 프롬프트: `assets/art-direction.md`.

## 개별 식사 / Full HD 업데이트

- 음식의 나눠주기를 누르면 네 사람의 배분 창이 열립니다. 사람별 부족량 범위에서 나눠 줄 양을 지정하고 확정합니다.
- 음식을 모두 배분한 뒤에만 확정할 수 있습니다. 모든 가족의 부족량보다 음식이 많으면 초과분은 소모된다고 표시합니다. 취소하면 음식과 포만도는 바뀌지 않습니다.
- 비상식량 25도 같은 방법으로 나눠 줍니다. 각자의 포만도는 다음 날 0으로 초기화됩니다.
- 이전 저장의 합산 포만도는 나 → 배우자 → 아이 → 어르신 순으로 각 필요량까지 배분해 이전합니다. 돈, 가방, 유물, 날짜는 유지됩니다.
- 1920×1080 게임 화면을 창 크기에 맞춰 비율을 유지하며 확대/축소합니다. 음식 가방과 일지는 필요 시 내부 스크롤됩니다.
- 단순한 가족 장면: assets/family-simple.png. 증명사진 4인 시트: assets/family-portraits.png. 내장 image_gen 생성 프롬프트: assets/simple-art-prompts.md.
