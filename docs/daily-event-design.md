# 오늘도, 한 끼 — 하루 전환 사건 기획안

작성일: 2026-09-22 · 상태: 콘텐츠 설계 초안

## 목적

하루가 끝날 때 등장하는 사건은 단순한 보상·손실이 아니라 다음 날의 생존 방식을 바꾸는 선택이어야 한다. 현재의 ‘봉투 3개 중 하나를 고른 뒤 즉시 효과 적용’ 연출은 유지하되, 봉투를 연 뒤 상황에 맞는 대응 2~3개를 제시한다.

이 문서는 `hardcore-balance-design.md`의 난이도 규칙을 따른다. 비용·확률·필요량 변화는 실제 구현 시 해당 문서의 상한과 일자별 난이도에 맞춰 조정한다.

## 사건 유형

| 유형 | 역할 |
|---|---|
| 즉시형 | 돈, 음식, 불안 등 현재 자원을 바로 바꾼다. |
| 선택형 | 식량, 돈, 가족의 부담 중 하나를 감수하게 한다. |
| 하루 지속형 | 다음 날 가격, 필요량, 덱 구성을 바꾼다. |
| 연속형 | 오늘의 도움·거래가 며칠 뒤 후속 결과로 돌아온다. |
| 조건형 | 가족 구성, 동물, 보유 자원, 이전 선택에 따라 등장한다. |

## 1. 식량과 생필품

| 사건 | 상황과 선택 | 효과 초안 |
|---|---|---|
| 젖어 버린 식량 | 천장에서 물이 샌다. 포장지를 구하거나 젖은 부분을 버린다. | $3 지출로 보존 / 보관 음식 1개의 포만도 5 감소 |
| 이웃의 냄비 | 옆방에서 공동 식사를 제안한다. | 음식 1개를 내고 다음 날 자유 배분 가능한 죽 25 획득 / 거절 |
| 유통기한 없는 통조림 | 날짜가 지워진 통조림을 발견한다. | 그대로 먹기: 식량 20, 25% 확률로 다음 날 성인 1명의 필요량 +5 / $3에 끓이기: 안전하게 식량 15 |
| 작은 저장고 | 무너진 벽 뒤에 서늘한 공간이 있다. | $5로 수리하면 다음 밤 보관 한도 +1 / 지나치기 |
| 마지막 연료 | 남은 연료를 난방과 조리 중 어디에 쓸지 정한다. | 난방: 불안 -3 / 조리: 다음 날 처음 먹는 음식의 포만도 +8 |

## 2. 배급소와 거래

| 사건 | 상황과 선택 | 효과 초안 |
|---|---|---|
| 배급소의 사과문 | 어제의 배급 오류를 인정하는 공지가 붙었다. | 다음 날 첫 쿠지 구매 무료 |
| 찢어진 배급표 | 훼손된 표를 직원이 받아줄지도 모른다. | $2에 복구해 다음 날 쿠지 1회 무료 / 고철상에 $1로 판매 |
| 암시장의 품귀 | 특정 등급 식량을 찾는 사람이 늘었다. | 다음 날 지정 등급 음식의 판매가 +$3 |
| 창고 정리 | 상인이 물건 하나를 급히 처분한다. | 소모품 1종을 정가의 절반에 구매할 기회 / 지나치기 |
| 빚 장부 | 상인이 식량을 외상으로 내어 준다. | 비상식량 1개 획득, 이틀 뒤 $9 상환 / 거절. 미납 시 그날 암시장 구매 불가 |
| 내부자의 메모 | 배급소 직원이 종이 한 장을 건넨다. | $4 지불 시 다음 날 미구매 쿠지 2장의 등급 공개 / 거절 |

## 3. 가족

해당 가족이 살아 있을 때만 등장한다.

| 사건 | 상황과 선택 | 효과 초안 |
|---|---|---|
| 아이의 생일 | 아이는 오늘이 무슨 날인지 말하지 않는다. | 음식 1개로 작은 잔치: 불안 -6 / 노래를 불러준다: 불안 -2 |
| 배우자의 야간 일자리 | 짧은 일거리가 생겼지만 밤을 새워야 한다. | 일한다: $10 획득, 다음 날 배우자 필요량 +5 / 쉰다: 불안 -2 |
| 어르신의 조리법 | 버리던 부위를 먹을 수 있게 만드는 방법을 떠올린다. | 다음 날 처음 먹는 음식의 포만도 +8 |
| 낡은 가족사진 | 짐 속에서 예전 집의 사진을 찾았다. | 간직하기: 불안 -3 / 액자까지 판매: $6 획득 |
| 내가 먹었다고 해 | 가족 한 명이 자신의 몫을 다른 사람에게 양보하려 한다. | 평소대로 배분하기: 불안 -2 / 받아들이기: 다음 날 해당 인원 필요량 -5, 불안 +3. 1회 한정 |
| 빈자리의 식기 | 가족을 잃은 뒤 처음으로 식기를 정리한다. | 남겨 두기: 불안 -3 / 교환하기: 비상식량 1개 획득. 게임당 1회 |

## 4. 이웃과 방문자

| 사건 | 상황과 선택 | 효과 초안 |
|---|---|---|
| 문밖의 기침 | 옆집 사람이 먹을 것을 구한다. | 음식 1개 기부 / 문을 닫는다. 기부하면 이틀 뒤 ‘돌아온 그릇’ 발생 |
| 돌아온 그릇 | 빌려 간 그릇에 음식이 담겨 돌아왔다. | 비상식량 1개와 $4 획득 |
| 수리공의 부탁 | 수리공이 식사와 보관함 수리를 교환하자고 한다. | 음식 1개 제공 시 다음 두 번의 밤에 보관 한도 +1 / 거절 |
| 검문소의 손 | 검문원이 통행 대가를 요구한다. | $5 지불 / 음식 1개 제공 / 먼 길로 우회해 다음 날 나의 필요량 +5 |
| 수상한 투자 | 낯선 사람이 배급품을 빼돌릴 수 있다고 속삭인다. | $5 투자: 다음 날 50% 확률로 $12 회수, 실패하면 회수 없음 / 거절 |
| 익명의 배급 봉투 | 문틈 아래에 작은 봉투가 놓였다. | 자금 $5 이하이고 보관 음식이 없을 때 등장. 비상식량 1개 획득 |

## 5. 도시의 변화

| 사건 | 상황과 선택 | 효과 초안 |
|---|---|---|
| 한파 예고 | 밤새 기온이 내려간다는 방송이 나온다. | $4로 연료 구매 / 다음 날 생존 중인 사람 각각 필요량 +2 |
| 수도 복구 | 잠깐이나마 깨끗한 물이 흐른다. | 다음 날 처음 먹는 음식의 포만도 +10 |
| 정전된 시장 | 암시장의 조명이 모두 꺼졌다. | 다음 날 첫 구매에 한해 $3 할인, 첫 판매에 한해 판매가 -$2 |
| 배급품 재분류 | 저급 배급품 일부가 교체되었다. | 다음 날 덱의 F등급 2장을 D등급으로 교체. 바뀐 수량과 확률 표시 |
| 물자 압류 | 군인이 좋은 배급품부터 가져갔다. | 다음 날 덱의 B등급 1장을 F등급으로 교체. 보상 배급금 $5 지급 |
| 조용한 밤 | 경보도, 문 두드리는 소리도 없다. | 불안 -2. 추가 선택 없이 가족의 짧은 대사 표시 |

## 6. 반려동물

해당 동물을 입양했고 살아 있을 때만 등장한다.

| 사건 | 상황과 선택 | 효과 초안 |
|---|---|---|
| 개가 찾아낸 주머니 | 강아지가 무너진 계단 밑을 향해 짖는다. | $5 획득 |
| 문 앞의 으르렁거림 | 강아지가 낯선 발소리를 먼저 알아챈다. | 다음 2일 안에 발생하는 금전 강탈 사건의 손실 1회 방지 |
| 함께 덮은 담요 | 강아지가 잠들지 못하는 가족 곁에 눕는다. | 불안 -4 |
| 고양이의 사냥 | 고양이가 식량 창고의 쥐를 쫓아냈다. | 다음 밤 보관 음식 1개 추가 보존 |
| 반짝이는 전리품 | 고양이가 작은 금속 부품을 물어 온다. | $4에 판매 / 장난감으로 남겨 불안 -3 |
| 골목으로 향한 꼬리 | 고양이가 익숙한 골목으로 안내한다. | 따라간다: 다음 날 나의 필요량 +3, E등급 음식 1개 획득 / 돌아간다 |

## 등장과 밸런스 규칙

- 하루 전환마다 일반 사건 1개를 보여준다. 강아지·고양이 합류처럼 큰 고정 사건이 있는 날에는 일반 사건을 대체한다.
- 기본 편성 비율은 도움 30%, 거래·선택 40%, 위기 20%, 휴식·서사 10%로 시작한다.
- 같은 사건은 한 게임에 1회만 등장한다. 강제 손실 사건은 연속해서 등장하지 않는다.
- 돈이나 음식이 부족한 선택지는 비활성화하고, 비용 없는 대응을 하나 이상 둔다.
- 사건 자체로 가족을 즉시 사망시키지 않는다. 다음 날의 부담을 미리 보여주고 준비할 시간을 준다.
- 미래 보상이나 상환이 있는 사건은 7일 안에 결과가 나오는 시점에만 등장한다.
- 확률형 선택에는 성공 확률과 실패 결과를 표시한다.
- 보관 한도 효과는 다음 밤 정리 시점, 필요량과 가격 효과는 다음 날 하루로 명확히 표기한다.
- 하드코어 밸런스 적용 후 일반 사건의 강제 비용은 최대 $5 또는 식량 10 상당에서 시작한다. 필요량 증가는 일자 배율·불안과 별도로 표시하며 같은 날 중첩하지 않는다.
- E/F 하위상의 손실 구조를 무력화하는 판매 보너스 사건은 제외한다. 음식 포만도 증가는 공통 상한을 적용한다.

## 첫 구현 추천 12종

배급소의 사과문, 젖어 버린 식량, 마지막 연료, 암시장의 품귀, 내부자의 메모, 아이의 생일, 배우자의 야간 일자리, 문밖의 기침, 돌아온 그릇, 한파 예고, 개가 찾아낸 주머니, 조용한 밤.

이 12종은 자원 획득·손실, 가족 선택, 다음 날 전략 변화, 이전 선택의 후속 결과를 모두 시험할 수 있는 첫 묶음이다.
